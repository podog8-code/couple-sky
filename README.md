# 情侣空间 · 光遇启动页

这个文件夹是一个可以直接部署的静态网页。把链接发到 QQ 后，会显示成带「情侣空间」标题和封面的分享卡片；点开链接后会自动尝试打开手机上的光·遇。

## 文件

- `index.html`：落地页 + QQ 分享卡片 meta + 自动唤起光遇的脚本
- `og-cover.png`：QQ 分享卡片封面（1200 × 630）

## 部署

1. 把这两个文件上传到任意 HTTPS 静态托管，例如 GitHub Pages、Vercel、Netlify、Cloudflare Pages，或自己的服务器。
2. 打开 `index.html`，把里面的 `https://YOUR_DOMAIN/...` 全部替换成你部署后的真实地址。
3. 用浏览器访问部署后的地址，确认页面能正常打开。
4. 把地址发到 QQ 聊天窗口，QQ 会抓取标题、描述和封面，显示成卡片。

如果 QQ 里显示的是旧卡片，多半是 QQ 缓存了之前的抓取结果，可以在链接后面加一个版本参数，例如 `https://你的域名/?v=2`。

## 唤起逻辑

- 安卓：页面会直接尝试 `ntes://game.mobile/game75/` 拉起光遇；如果没安装，会自动跳转到网易官方下载页。
- iOS：页面会跳到网易官方 Universal Link，已安装光遇时直接打开，未安装时显示官方下载页。
- QQ 内置浏览器：QQ 会拦截 App 跳转，页面会保留“打开光·遇”按钮，并提供“官方启动页”兜底。遇到这种情况，点右上角“在浏览器打开”后通常就能自动唤起。

页面里的唤起地址都来自网易官方光遇配置，不是自定义协议，所以更稳。

## 自定义文案

想改卡片标题、描述或页面文字，直接编辑 `index.html`：

- QQ 卡片标题：`<meta itemprop="name" content="情侣空间">` 和 `og:title`
- QQ 卡片描述：`<meta name="description" ...>` 和 `og:description`
- 页面大标题：`<h1>光是遇见就很美好</h1>`
- 页面副标题：`.subtitle`
